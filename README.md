# Amazon Mobiles Data Analysis

## About the Project
This project is based on analyzing mobile phone data collected from Amazon. The main aim was to understand the dataset, clean it properly, and find useful insights using data analytics techniques.
I worked on this project as part of my learning and internship tasks, where I applied concepts like data cleaning, exploratory data analysis (EDA), and data visualization.

## Tools Used
- Python  
- Pandas  
- NumPy  
- Matplotlib  
- Google Colab  

## Dataset
The dataset contains information about mobile phones such as product names, prices, ratings, and other details.

## What I Did
- Cleaned and prepared the dataset for analysis  
- Explored the data to understand patterns and trends  
- Created graphs and charts to visualize the data  
- Extracted meaningful insights from the dataset  

## Key Findings
- Some brands have a higher number of products compared to others  
- Most mobile phones fall under a specific price range  
- Price and rating do not always have a strong relationship  
- A few products had unusually high or low values (outliers)  

## What I Learned
- How to work with real-world datasets  
- Importance of data cleaning before analysis  
- How to use visualization to explain data  
- Improved my analytical thinking and problem-solving skills
